# BuildSpace — Project Showcase & Feedback Board

A responsive community project board made with plain HTML, CSS, and JavaScript.

## Features
- Submit projects with a title, description, category, live demo link, and GitHub link
- Project cards with technology tags and author information
- Search projects by title, description, author, or technology
- Filter by Web, AI, Mobile, and Design
- Like projects (the same browser user cannot repeatedly like/unlike without toggling)
- Add short comments to projects
- Saves projects, likes, and comments in browser localStorage
- Responsive layout for desktop and mobile

## Run it
1. Extract the folder.
2. Open `index.html` in VS Code.
3. Use Live Server, or open `index.html` directly in a browser.

Note: This is a front-end demo. Data is saved only in the current browser; it is not shared with other users or synced to a server.
